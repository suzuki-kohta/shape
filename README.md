# Interactive 3D Wallpaper

数式からの曲面生成と、マウスでの点プロット・結線に対応した Three.js 製の Web 壁紙です。ソースフォルダーを Wallpaper Engine に読み込むか、ビルドした `dist` フォルダーを読み込んで使えます。

## 開発

```sh
npm install
npm run dev
```

## Wallpaper Engine 用ビルド

```sh
npm run build
```

生成された `dist` には `index.html`、ローカルの JavaScript ライブラリ、`project.json`、プレビュー画像が含まれます。Wallpaper Engine の「壁紙を開く」から `dist` フォルダー（またはソースフォルダー）を選んでください。相対 URL を使うため、Web サーバーへ配置せずローカルで読み込めます。

## 操作

- **視点回転**: 回転モードでドラッグ、ホイールでズーム。パンモードではドラッグで視点を移動。
- **点の作成**: 点打ちモードで XY 平面をクリックし、続けて高さをクリック位置またはホイールで調整して確定。右クリックまたは `Esc` で高さ指定を取り消し。
- **数式曲面**: 上部パネルで明示関数または媒介変数を選び、プリセットか数式を指定して「立体を生成」。
- **便利な操作**: `H` で UI 表示切替、`T` でテーマ切替、`Ctrl+Z` で点を Undo。

作成した数式、点、表示設定はブラウザーの `localStorage` に保存されます。

## Wallpaper Engine で重い・不安定な場合

省電力モードは静止時に描画ループを止めます。さらに描画解像度を最大 1.5 倍に制限し、アンチエイリアス・影・背景粒子数を抑えています。Wallpaper Engine 側でも、まず画質・解像度を下げて負荷を確認し、問題が続く場合は「空間パーティクル」をオフにしてください。数式の曲面を表示している場合は、ワイヤーフレーム表示にすると描画負荷が下がります。
